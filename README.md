 # SERVICES FOR Windows

> 声明：本文作者是中国人！！！

SERVICES FOR Windows，字面意思，就是面向Windows的服务。该项目其实从2025年10月就开始了，但是直到2026年4月才正式开始进入Github。

## 说在前面

SERVICES FOR Windows （以下简称SFW）是什么呢？它是用c++技术基于Windows x64系统开发的一款类似控制台的软件，有一个十分简陋的用户交互设计，只能通过输入选项的数字来选择选项。该项目由"Z-92jf 加法工作室"开发。

## 介绍

1. 可以浏览我们基于Github提供的Pages服务开发的网页[一个为Windows系统服务的快速工具箱](https://z-92jf.github.com)

2. 这是一款基于Windows x64版本的面向Windows 11的工具箱（截至2024年4月8日），后续将开发基于Windows x32包括Windows 10的

## 安装和使用

> 终于讲到重点了！！！！！

那我们的应用如何安装呢？我们后续会在官网发布详细的安装教程，不过在此，我们还是详细讲一讲。

#### 第一步：下载

从[我们的仓库](https://github.com/z-92jf/SERVICES-FOR-Windows)下载您喜欢的版本的安装包，并解压。

双击Setup xxxxx.exe，按照指示下载就好了！推荐使用管理员身份运行。安装目录附赠部分源代码。

#### 第二步：使用

下载好了，一切准备就绪！您可以双击桌面上的快捷方式（如果有），或者搜索SERVICES FOR Windows，找到main.exe，双击运行。
